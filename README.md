# Fraudulent Job Listing Detection

## Overview

This project applies Natural Language Processing (NLP)
techniques to classify fraudulent job listings.

## Research Questions

1. How effective are BOW and TF-IDF models?
2. Which words are associated with fraudulent listings?
3. Does adding company and geographic information improve performance?

## Tools

- Python
- Pandas
- NumPy
- NLTK
- Scikit-Learn
